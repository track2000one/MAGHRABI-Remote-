# MAGHRABI Remote

منصة شخصية للوصول الآمن عن بعد إلى جهاز المنزل عبر واجهة ويب مبنية باستخدام React + Vite + TypeScript.

## الحالة الحالية

هذه هي النسخة الأولية لواجهة المشروع، وسيتم تطويرها تدريجيًا لإضافة إدارة الأجهزة، حالة الاتصال، سجل الجلسات، والأمان.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
npm run preview
```

## التقنية

- React
- Vite
- TypeScript
- RTL عربي
- Responsive UI

## ملاحظات أمنية

لا تحفظ كلمات مرور RustDesk أو مفاتيح الوصول أو أي أسرار داخل المستودع. استخدم متغيرات البيئة للخدمات الخلفية عند إضافتها لاحقًا.
